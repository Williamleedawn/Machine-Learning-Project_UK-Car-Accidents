## How to Run

### One-click pipeline (recommended)

```bash
python main.py
```

**Runtime estimates:**
- With cached results (Phase 11-13 results exist): ~5-8 minutes
- Without cache (first run, Phase 1-10 only): ~10 minutes
- Full run including GridSearchCV and ablation: ~12 hours

Phase 11-13 automatically detect existing results and load from cache. If no cache exists, they will run the full computation.

### Standalone scripts (for long-running operations)

These scripts were used during development and support checkpoint-based resumption:

```bash
# Run after main.py has completed Phase 1-7 (creates phase7_data.pkl)
python run_ablation.py    # Imbalance ablation (~3 hours, checkpoint-resumable)
python run_tuning.py      # GridSearchCV (~9 hours, checkpoint-resumable)
python run_phase12.py     # Final evaluation + all figures (~30 minutes)
```

### Jupyter notebook

```bash
cd notebooks
jupyter notebook full_pipeline.ipynb
```

The notebook runs Phase 1-10 live and loads cached results for Phase 11-13.

## Explanation of Results Folder

The `.pkl` files in the original experimental output directory are mainly used to store intermediate data caches or the trained model pipeline. Specifically, `phase7_data.pkl` is a phase data cache, primarily used to skip repetitive data preprocessing steps; `tuning_RandomForest_best_pipeline.pkl` is the serialization file for the random forest model, but it is quite large. Therefore, both complete PKL files have been uploaded to the corresponding projects on GitHub for archiving, and not included in the commit ZIP.
Github URL: [Williamleedawn/Machine-Learning-Project_UK-Car-Accidents](https://github.com/Williamleedawn/Machine-Learning-Project_UK-Car-Accidents)
Note: You can download `phase7_data.pkl` from [Google Drive](https://drive.google.com/file/d/1N51xRFdlAGriNf_ucDrDHmf2St6rD4oe/view?usp=sharing) and `tuning_RandomForest_best_pipeline.pkl` from [Google Drive](https://drive.google.com/file/d/1bJTy7IR64k5mHJhEcg6rB0b0sJEOmDRy/view?usp=sharing) too and place it under `outputs/results/`.
